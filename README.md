# FreshRSS Extensions

Collection of custom extensions for FreshRSS.

## Available Extensions

- **[xExtension-ContentCleaner](./xExtension-ContentCleaner)**: Cleans up author boxes and commercial/advertisement paragraphs from article content and prevents overwriting existing entries.
- **[xExtension-TitleCleaner](./xExtension-TitleCleaner)**: Cleans HTML entities (e.g. `&amp;` -> `&`) and strips HTML tags from entry titles automatically.
